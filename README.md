# 🛍️ Calculadora de Gastos Shopee

Extensão para Google Chrome que ajuda a acompanhar os gastos com compras na Shopee Brasil, reunindo os valores dos pedidos em uma interface simples e prática.

## ✨ Funcionalidades

- 📦 Contagem dos pedidos encontrados na página.
- 🧾 Separação dos pedidos comprados e cancelados ou reembolsados.
- 💰 Cálculo dos valores por categoria.
- 🧮 Exibição da soma total dos pedidos identificados.
- ⚡ Cálculo diretamente a partir dos pedidos carregados na página Minhas Compras.

## 🚀 Como utilizar

1. Acesse sua conta na Shopee Brasil.
2. Abra a página [Minhas Compras](https://shopee.com.br/user/purchase).
3. Aguarde os pedidos que deseja analisar carregarem.
4. Abra a extensão Calculadora de Gastos Shopee.
5. Clique em **Calcular Gastos**.
6. Consulte os totais apresentados.

## 💻 Instalação para desenvolvimento

1. Clone este repositório:

   ```bash
   git clone https://github.com/rennanareas/Shopee-Calculator.git
   ```

2. Abra `chrome://extensions` no Google Chrome.
3. Ative o **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta do projeto que contém o arquivo `manifest.json`.
